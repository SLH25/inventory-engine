# Inventory Engine

An object-oriented Python inventory management engine.

## Features

- Object-oriented architecture
- Inheritance
- Encapsulation
- Polymorphism
- Custom exceptions
- Inventory management
- JSON persistence
- CSV persistence
- Unit testing
